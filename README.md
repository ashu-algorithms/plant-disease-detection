# 🌿 Plant Disease Detection Using Machine Learning

An end-to-end Deep Learning Computer Vision project developed as a college assignment capstone. The system automatically classifies plant leaf pathology from digital photographs and provides actionable agronomic remediation protocols using a Convolutional Neural Network (CNN) and an interactive Streamlit web dashboard.

---

## 📌 Project Overview
Crop diseases represent a primary cause of agricultural yield loss globally. Early and accurate leaf symptom identification allows farmers and agronomists to apply targeted organic or chemical treatments before pathogens spread across entire fields.

This application provides:
- **Instant AI Pathology Diagnosis:** Upload leaf photos in JPG, JPEG, or PNG format.
- **Diagnostic Confidence Score:** Real-time probability estimation generated by a trained CNN.
- **Actionable Treatment Plans:** Detailed symptom descriptions, chemical/organic fungicide recommendations, and cultural preventative measures for each condition.
- **Transparent Model Performance:** In-app inspection of accuracy curves, loss curves, confusion matrices, and classification reports.
- **Interactive Sample Gallery:** Pre-loaded benchmark leaf samples for one-click testing without manual image searches.

## ⚙️ Quick Start: Terminal Commands

### 1. Clone or Navigate to the Workspace
```powershell
cd d:\Plant-Disease-Detection
```

### 2. Install Required Dependencies
```powershell
py -m pip install -r requirements.txt
```

### 3. (Optional) Re-train the CNN Model
> **Note:** A genuine pre-trained model `models/plant_model.keras` is already provided and verified in the repository. If you wish to retrain from scratch:
```powershell
py train.py
```
This command:
1. Verifies/downloads the dataset into `dataset/`.
2. Partitions images into stratified Train (70%), Val (15%), and Test (15%) splits.
3. Trains the 4-block CNN architecture with data augmentation and learning rate scheduling.
4. Evaluates unseen test images and saves the final model to `models/plant_model.keras`.
5. Exports `models/training_history.png` and `models/confusion_matrix.png`.

### 4. Test Model Inference via Command Line (CLI)
You can test predictions directly from the terminal without starting the web UI:
```powershell
# Run self-test on sample library:
py predict.py

# Or pass any custom image:
py predict.py samples\sample_Tomato___Early_blight.jpg
```

### 5. Launch the Streamlit Web Application
```powershell
py -m streamlit run app.py
```
The browser will automatically open at:
```
http://localhost:8501
```

## 🧠 Model Architecture & Training Methodology
The neural network uses a sequential hierarchical convolutional design:

1. **Input Rescaling Layer:** Normalizes 8-bit RGB integers `[0, 255]` to floating-point tensors `[0.0, 1.0]`.
2. **Data Augmentation:** Random horizontal flipping, random rotation (±8%), and subtle zoom (±8%) to prevent overfitting on orientation artifacts.
3. **Convolutional Feature Extractors:** 4 sequential blocks:
   - Block 1: `Conv2D(32, 3x3, ReLU)` + `MaxPooling2D(2x2)`
   - Block 2: `Conv2D(64, 3x3, ReLU)` + `MaxPooling2D(2x2)`
   - Block 3: `Conv2D(128, 3x3, ReLU)` + `MaxPooling2D(2x2)`
   - Block 4: `Conv2D(128, 3x3, ReLU)` + `MaxPooling2D(2x2)`
4. **Classification Head:**
   - `Flatten` feature map layer
   - `Dense(128, ReLU)`
   - `Dropout(0.35)` for regularization
   - `Dense(10, Softmax)` output layer delivering normalized probability distributions.
5. **Loss & Optimizer:** `Adam` optimizer with `sparse_categorical_crossentropy` loss and learning rate decay (`ReduceLROnPlateau`).
